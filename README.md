# Experiencias sin Límites RD

Prototipo web de una agencia de turismo inclusivo en la República Dominicana, con una plataforma para buscar, planificar y reservar experiencias accesibles.

**Proyecto Emprendedor II · Grupo 1**
Michel Arno del Rosario · Angel Jadriel Garcia Quezada · Cristopher N. Núñez Martínez · David Matos

## Qué incluye

- **Sitio para visitantes:** destinos con ficha de accesibilidad, filtros por tipo de discapacidad y por necesidad, versión en lectura fácil, lectura en voz alta y solicitud de reservas.
- **Panel de la agencia:** solicitudes, clientes, destinos y fichas, excursiones, disponibilidad, proveedores y reportes, con exportación de reservas a CSV.
- **Ajustes de accesibilidad:** tamaño del texto, alto contraste y espaciado amplio.

Todo está en un solo archivo, `index.html`. No necesita servidor, base de datos ni instalación.

## Publicarlo en GitHub Pages

1. Crea un repositorio **público** en GitHub, por ejemplo `experiencias-sin-limites-rd`.
2. Sube `index.html` y este `README.md` a la raíz del repositorio con **Add file → Upload files** (en un repositorio vacío aparece como *uploading an existing file*) y confirma con **Commit changes**.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Source: Deploy from a branch**, la rama `main` y la carpeta `/ (root)`. Pulsa **Save**.
5. En unos minutos el sitio queda en `https://TU-USUARIO.github.io/experiencias-sin-limites-rd/`. La dirección exacta aparece en la misma página de **Pages**.

Con una cuenta gratuita, GitHub Pages solo funciona con repositorios públicos.

## Verlo sin publicar

Abre `index.html` con doble clic en cualquier navegador.

## Sobre los datos

- Los destinos son reales. Las fichas de accesibilidad, proveedores, clientes y reservas son datos de ejemplo para la demostración.
- No hay servidor: lo que cada persona agrega o cambia se guarda solo en su propio navegador y nadie más lo ve.
- Para volver a los datos iniciales: **Administración → Resumen → Restablecer datos de ejemplo**.

## Ruta sugerida para la demostración

1. En **Inicio**, elige «Motora» para ver el filtro por tipo de discapacidad.
2. Abre la ficha de **Cueva de las Maravillas**: estados verificados y por verificar, lectura fácil y botón para escuchar.
3. En **Reservar**, usa «Rellenar con un ejemplo» y envía la solicitud.
4. Pulsa «Ver la solicitud en el panel» para revisarla, asignar proveedores y confirmarla.
5. Termina en **Reportes** y en la página **Proyecto**.
